BACKGROUND: how myWaterVolume is currently accrued (verified - map it yourself before editing)
------------------------------------------------------------
Hot path: HydrodynamicApproximation=DynamicWave_, GridIsConstant=.true., LimitToCriticalFlow=.true. Per sub-iteration the order is: ComputeFaceVelocityModulus -> DynamicWaveXX(=_default_CG) -> DynamicWaveYY(=_default_CG) -> SetWorkSize -> ... -> UpdateWaterLevels. The staggered-grid divergence of cell (i,j) is (lFlowX(i,j) - lFlowX(i,j+1) + lFlowY(i,j) - lFlowY(i+1,j)) * LocalDT. The CURRENT code applies it SCATTERED across three routines:
  - DynamicWaveXX_default_CG (LimitToCriticalFlow branch, ~L11908-11916): applies ONLY the X-inflow:
        Me%myWaterVolume(i,j) = Me%myWaterVolume(i,j) + lFlowX(i,j)*LocalDT
        Me%ActivePoints(i,j) = 1 ; Me%ActivePoints_Left(i,j) = 1
    It does NOT subtract the X-outflow lFlowX(i,j+1) because that would write cell (i,j) while iterating face-column j+1 - a cross-column write under the j-parallel OMP loop. So it is DEFERRED (see UpdateWaterLevels).
  - DynamicWaveYY_default_CG (LimitToCriticalFlow branch, ~L13126-13135): applies the FULL Y-divergence inline (same column, race-free):
        Me%myWaterVolume(i,j)   += lFlowY(i,j)*LocalDT   (Y-inflow to (i,j))
        Me%myWaterVolume(i-1,j) -= lFlowY(i,j)*LocalDT   (Y-outflow from (i-1,j))
        Me%ActivePoints(i,j)=1 ; Me%ActivePoints(i-1,j)=1
  - UpdateWaterLevels (GridIsConstant branch ~L14084-14090; GridIsVariable branch ~L14120-14126): completes the deferred X-outflow:
        if (Me%ActivePoints_Left(i,j+1) == 1) then
            Me%myWaterVolume(i,j) -= lFlowX(i,j+1)*LocalDT
            Me%ActivePoints(i,j) = 1
        endif
    then does the negative-volume/Restart check (AllmostZeroNegative), myWaterColumn = WaterVolume/GridCellArea, and the OpenPoints/ActivePoints wet/dry decision (THIS is the Phase-1 cell-flip point).

Net accrual order for cell (i,j): init, then +lFlowX(i,j)*dt (XX), then +lFlowY(i,j)*dt (YY face i), then -lFlowY(i+1,j)*dt (YY face i+1), then -lFlowX(i,j+1)*dt (UpdateWaterLevels). Each term is (real8 flow * real4 dt) added to the real8 myWaterVolume separately, in that order.
